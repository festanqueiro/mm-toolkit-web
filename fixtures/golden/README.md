# Golden fixtures

Generated by [`scripts/generate_golden.py`](../../scripts/generate_golden.py) from the **real desktop engine**. `golden.json → generatedFrom` records the desktop version and commit. **Never edit by hand.**

```bash
# from this repo's root, with the desktop repo checked out next to it and its venv set up
MM_TOOLKIT_DESKTOP=../record-label-mediatools \
  ../record-label-mediatools/.venv/bin/python scripts/generate_golden.py
```

| Path | Contents |
|---|---|
| `golden.json` | Every expected value: `pure.*`, `audio.tracks[]`, `effects.cases[]` (with a `parity` level each) |
| `audio/*.wav` | Synthetic 11025 Hz 16-bit tracks: quiet intro + bass "drop" at a known time; one is shorter than the 20 s search skip |
| `frames/*.png` | 64×48 effect inputs and outputs (`input.png`, `background.png`, `overlay-rgba.png`, then one PNG per case) |

Parity levels and tolerances are defined in [`docs/specs/12-testing-and-parity.md`](../../docs/specs/12-testing-and-parity.md).
